Schema: programmes

Column definitions for programmes.csv and programmes.json. The matrix, outcome and dataset files are documented in the repository README.

FieldType Meaning
idstringStable programme identifier, P01–P67. Cite this, not the row number.
programmestringProgramme or shock name as commonly used.
domainstringPolicy domain.
agencystringImplementing agency or agencies.
scopestringGeographic scope as stated by the programme.
start_yearstringFirst year of operation, including pilots.
rollout_windowstringNarrative description of the phasing, with dates where known.
rollout_unitstringThe unit that switches on — district, tehsil, facility, lot.
n_districtsstringNumber of treated units, as narrative because it changes over phases.
staggeringstringThe form the staggering takes.
assignmentstringHow units were selected into each phase.
timing_sourcestringWhere district-by-date treatment data can be obtained.
timing_qualitystringAssessed reliability of the above, with reasoning.
quality_labelstringHigh / Medium-High / Medium / Low-Medium.
quality_rankinteger3 / 2 / 1 / 0, for sorting.
identificationstringCandidate design and why it works here.
threatsstringMain threats to identification for this entry.
evidencestringPublished evaluations, where any exist.
regionslistNormalised province and region tags.
unit_classstringNormalised rollout unit.
erastringNormalised start period.
methodslistDesigns the entry suits, derived from the identification note.
readybooleanTrue where quality_rank is 2 or 3.
n_outcomesintegerNumber of mapped outcomes in the matrix.

Reading the data in

Stata

import delimited using ///
  "programmes.csv", ///
  varnames(1) encoding("utf-8") clear

keep if quality_rank >= 2
list id programme start_year, clean

R

library(readr)
p <- read_csv("programmes.csv")
subset(p, quality_label == "High",
       select = c(id, programme, start_year))

What is not here

This catalogue holds metadata about programmes, not the district-by-date treatment files themselves. Those have to be obtained from the sources named on each programme page — see finding treatment dates. If you build one, contribute it and it will be hosted here with attribution.
