Programme × outcome matrix

All 322 programme–outcome pairs in one filterable table. Each row names the mechanism that would produce the outcome, the expected direction, the dataset that measures it, and an honest note on whether the analysis is actually feasible with existing data.

Expected signs are hypotheses derived from the stated mechanism, not findings.
