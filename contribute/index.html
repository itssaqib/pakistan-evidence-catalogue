Participation

Contribute, claim or correct

This catalogue is more useful if it is shared and corrected. Four ways to take part, in rough order of how much they help.

Most valuable

Contribute a treatment-timing file

If you have assembled a district-by-date rollout file for any entry here, contributing it saves the next researcher months. It will be hosted with your name on it and a DOI, and the programme page will link to it.

Send a timing file

Claim an idea

If you are actively working on an entry, say so and it will be marked Claimed with your name and expected timeline, so others do not duplicate the work. Claiming does not reserve anything — it is a coordination signal, not a property right.

Claim an entry

Correct a date or a claim

Dates in secondary sources disagree routinely. If you have a primary document that contradicts something here, that correction is worth more than a new entry. Include the document or a citation.

Submit a correction

Suggest a programme

Coverage is strongest for Punjab and thinnest for Balochistan. Suggestions from the under-covered provinces are especially welcome. The bar is simple: did it reach different places at different times, and can that be dated?

Suggest a programme

What an entry needs

Nothing here is hard to supply, but an entry without a timing source is not usable, so that field is the one that matters.

  • Name and implementing agency — as officially used.
  • Geographic scope — national, or which provinces.
  • Rollout window — when phases began and ended, with dates.
  • Rollout unit — district, tehsil, facility, scheme lot.
  • Assignment rule — how units were picked for each phase. If there was a threshold on a measurable variable, say so; that is the most valuable single fact.
  • Timing source — the register, document or dataset where the district-by-date schedule can actually be found.
  • Known evaluations — so the catalogue does not send people to re-do finished work.

How contributions are handled

  1. Submissions are reviewed against the primary source named.
  2. Accepted entries go into the next versioned release, with the contributor credited on the entry and in the changelog.
  3. Corrections to existing entries are applied with a note recording what changed.
  4. Contributed data files are released under CC BY 4.0 unless you specify otherwise.

On co-authorship

Contributing to the catalogue is not a claim on anyone's paper, and does not create one. If you want to work together on a specific entry, that is a separate conversation — say so directly rather than through a contribution.
