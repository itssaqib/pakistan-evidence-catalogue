IDP registration and phased return to merged districts

Administratively scheduled staggered returns. Rolled out by tehsil across 7 agencies, phased return schedules by agency and tehsil, 2015-2018.

Where to get district-by-date data

FDMA return notifications; UNHCR and IOM return monitoring; HDX

Assessed quality: Medium-High. Verify against the primary document before use — dates in press coverage and programme retrospectives frequently disagree by a year. How to obtain timing data →

Identification

Return dates are administratively set rather than chosen by households, which is a much better source of variation than the operations themselves. Combine with KP MICS 2019.

Main threats to identification

Returnees are selected; destination infrastructure was rebuilt simultaneously

Existing evidence

Very thin
