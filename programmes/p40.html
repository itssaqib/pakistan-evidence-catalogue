Identification

Only 7 treated units, so use synthetic control rather than standard DiD. Outcomes: reported crime by category, traffic violations, response times.

Main threats to identification

Very few treated units; simultaneous traffic enforcement changes

Existing evidence

None known

Outcomes and data (4)

Each row pairs an outcome with the mechanism that would produce it, the expected direction, and a dataset that measures it at a compatible resolution. Expected signs are hypotheses, not findings.
